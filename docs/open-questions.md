# EPN Open Questions Log

As specified in Section 18 of the Build Specification, these questions are logged for stakeholder alignment with EPN management while implementation proceeds with configurable defaults:

1. **Brand Identity**: Logo files, typography choices, and confirmation of working title "EPN OnePharm". *(Default: Clean clinical neutral palette, accessible blue primary, sans-serif typography)*.
2. **2026–2030 Strategic Plan Pillars**: Exact pillar names and definitions. *(Default: Seed 2021–2025 pillars with dynamic admin editor to add 2026–2030 pillars without code changes)*.
3. **Health Priority Taxonomy**: Confirm unification of IPC and AMR into a single priority with dual tagging. *(Default: Seeded with tag rollup)*.
4. **Headline Statistics Reconciliation**: Labeling 149 members across 38 global countries vs 29 African member countries, 25,000 health facilities, and 300 million population served. *(Default: Dual badge display explaining geographic context)*.
5. **Facility Master Lists**: Official authoritative sources for Kenyan FOSAs (Master Facility List / KMFL) and priority countries.
6. **Data-Sharing Agreement Defaults**: Standard visibility matrix per member type and data category.
7. **Subscription Pricing Schedule**: Hourly, daily, monthly, and annual token pricing for registered, basic, pro, and full tiers.
8. **Medstock Pilot Sites & Tracer List**: Detailed specification of the 14-49 essential medicines list items for initial deployment.
